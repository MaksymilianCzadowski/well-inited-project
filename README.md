# 🛠️ Well inited project

This repository provides a standardized starting point for projects with **Husky**, **linting rules**, and other best development practices. 

## 📌 Project Structure  
Each **branch** in this repository represents a preconfigured project with a specific environment (e.g., TypeScript, React, Node.js, etc.). This allows developers to start with a clean setup without manually configuring everything from scratch.  

## ✅ Features  
- 🔧 Standardized setup with **Husky** (Git hooks)  
- 🔍 Predefined **linting rules** tailored to each project  
- 🚀 Ready to use right after cloning  

## 🚀 Usage  
1. **List available branches**  
   ```bash
   git branch -r
   ```  
2. **Clone a specific branch**  
   ```bash
   git clone -b <branch-name> --single-branch <repo-url>
   ```  
3. **Install dependencies and start developing**  
   ```bash
   npm install # or yarn install
   ```  

This project ensures a clean and consistent setup across different types of projects. 🚀
